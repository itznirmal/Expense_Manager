# Expense Manager — Agent Guidelines

All implementation agents, reviewers, and resource specialists operating in this workspace must adhere to:

1. **`ios-developer` Skill**: Modern Swift, SwiftUI, SwiftData, Swift Concurrency, Clean MVVM (`@Observable`), Swift Charts, and Apple Human Interface Guidelines.
2. **`ios-reviewer` Skill**: 3-Axis adversarial review (Standards, Spec, Adversarial/Edge Cases).
3. **Gauntlet Quality Protocol**: Evidence-driven `BUILD → RUN → OBSERVE → CRITIQUE → FIX → VERIFY` cycle with frozen `QUALITY_BAR.md`, issue ledger `ISSUES.md`, and `CHECKPOINT.md`.
4. **Financial Precision**: All monetary values are `Decimal`.
4. **Offline First & Privacy**: Local SwiftData storage, biometric lock support, secure sanitized exports.
5. **Autonomy & Continuity**: Master Orchestrator delegates tasks to subagents in systematic vertical slices and iterates until full completion.
